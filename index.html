How to use this mirror

  1. Add the mirror once Run the install script or add the APT source to your server.
  2. Pick a package Browse the catalog above — each card shows the install command.
  3. Install with APT sudo apt update && sudo apt install <package-name>
  4. Follow package docs Some packages include a setup command (e.g. himosoft-k3s-server install). Others are ready after install.
